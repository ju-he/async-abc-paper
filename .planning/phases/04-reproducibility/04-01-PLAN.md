<objective>
Add a pytest test to `experiments/tests/test_extend.py` proving that `--extend` on a partially populated CSV produces the same final row set as a fresh run with the same config and seed. This satisfies REPR-01: no silent incorrect merges when extending.

Purpose: REPR-01 currently only has tests that check extend skips duplicates and runs only missing combinations. It does NOT verify that the extended output is IDENTICAL (as a row set) to a fresh run. Without this, a silent bug (e.g. seed drift between extend and fresh, partial row being reused when it shouldn't be, etc.) would not be caught.

Output: One new test function in the existing `TestExtendBasicRunner` class (or a new class) that:
1. Runs `gaussian_mean_runner.py` fresh, captures its CSV as ground truth.
2. In a second tmp_path, writes a PARTIAL CSV (a subset of the ground-truth rows — e.g. only `rejection_abc, replicate=0` present).
3. Runs `gaussian_mean_runner.py --extend` in that second tmp_path.
4. Asserts the extended CSV's row set (on stable key columns) equals the ground-truth CSV's row set.
</objective>
